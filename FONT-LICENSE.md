# Excalifont

`Excalifont-Regular.woff2` is the hand-drawn typeface used by Excalidraw,
released under the **SIL Open Font License, Version 1.1**.

The OFL permits embedding the font in a document or application, including
commercial ones. It requires that the font itself is not sold on its own and
that this notice travels with the font file.

Full licence text: https://openfontlicense.org/

The subset here is the Latin subset shipped in the `@excalidraw/excalidraw`
npm package (v0.18.0), about 25 KB.

# Bricolage Grotesque

`fonts/bricolage-grotesque-latin-800-normal.woff2` is ARGH!'s display face,
by Atelier Triay, released under the **SIL Open Font License, Version 1.1**.
The same terms apply: embedding is fine, selling the font on its own is not,
and this notice travels with the file.

Project: https://github.com/ateliertriay/bricolage
Full licence text: https://openfontlicense.org/

The subset here is the Latin 800 subset shipped in the
`@fontsource/bricolage-grotesque` npm package (v5.3.0), about 21 KB. 800 is the
only weight the site uses, because the system has one display weight.
